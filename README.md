# JM Trade Group website

English-language Astro site for the JM Trade Group homepage.

## Run locally

```sh
npm install
npm run dev
```

## Content updates

- Change service labels, contact details, founder information, and company figures in `src/data/site.ts`.
- The company logo supplied for the site is stored at `public/images/jm-trade-logo.png`.
- Replace the hero poster at `public/images/harbor-hero.png` when the final visual is ready.
- Add the approved looping hero footage at `public/video/jmtrade-hero.mp4`. The page already uses that path and displays the poster as a fallback.
- Founder photos were cropped from the screenshots supplied in `JM-trade-ss`.

The `/china/` route is a temporary destination page. Its detailed content and metric pages are planned for a later step.
